# CPP-Learning-Journey

My C++ practice programs, written while learning the language from the basics.
Many files hold several small exercises, with the earlier versions kept as
commented-out blocks so I can see how my solutions changed.

## What is inside

| Folder | Topics |
|---|---|
| `01-basics` | Data types, `cin` / `cout`, type conversion |
| `02-conditionals-and-loops` | if / else, `for` and `while` loops, tables, factorial, prime check, Fibonacci |
| `03-patterns` | Nested loops: star, number and letter patterns |
| `04-number-systems` | Binary, decimal and octal conversions |
| `05-functions` | Functions, pass by reference, swapping values |
| `06-arrays-and-strings` | Arrays, min / max, C-style strings and `std::string` |
| `07-practice-problems` | Armstrong number, pangram check, integer square root, number complement |

## How to run a file

```bash
g++ filename.cpp -o out
./out
```

This is a work in progress. I will keep adding programs as I learn more.
